# ABIR-X | Cyber Companion

## Project 2: Giga Pet

**Course:** COMP 484 – Web Development

**Student:** Abir Islam

## Project Description

ABIR-X is an interactive virtual robot pet created using HTML, CSS, JavaScript, and jQuery. Users can interact with the robot through different actions that affect its weight and happiness.

## Features

- **Treat:** Increases the robot's weight and happiness.
- **Exercise:** Decreases weight and happiness.
- **Play:** Increases happiness and decreases weight.
- **Sleep:** Allows the robot to rest.
- **Robot Animations:** Different animations appear when users interact with ABIR-X.
- **Pet Statistics:** Displays the robot's current weight and happiness.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery
- GitHub Pages
